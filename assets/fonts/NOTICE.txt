Both files here are subsets of that variable font, instanced at a fixed weight
(400 for Regular, 700 for Bold) and trimmed to the coverage the UI needs. They
were produced with fontTools (pyftsubset): instance the `wght` axis at the target
weight, then subset to the codepoint set below.

Coverage (the whole CJK block is included on purpose — a narrower GB2312 cut
left Traditional and rarer Hanzi with no glyph, and no host fallback behind it,
so they rendered as tofu):

  * ASCII and Latin-1, Latin Extended-A/B, IPA, spacing modifiers, combining
    diacritics
  * Greek, Cyrillic
  * general punctuation, super/subscripts, currency, letterlike symbols
  * arrows, math operators, misc technical, enclosed alphanumerics
  * box drawing, block elements, geometric shapes, misc symbols, dingbats,
    misc symbols and arrows
  * CJK symbols and punctuation, Hiragana, Katakana
  * CJK Unified Ideographs U+4E00–U+9FFF (covers Simplified and Traditional)
  * variation selectors, fullwidth and halfwidth forms

Regenerating:

  python - <<'PY'
  from fontTools import subset
  from fontTools.ttLib import TTFont
  from fontTools.varLib.instancer import instantiateVariableFont
  ranges = [(0x20,0xFF), (0x100,0x24F), (0x2B0,0x2FF), (0x300,0x36F),
            (0x370,0x3FF), (0x400,0x4FF), (0x2000,0x206F), (0x2070,0x209F),
            (0x20A0,0x20CF), (0x2100,0x214F), (0x2190,0x21FF), (0x2200,0x22FF),
            (0x2300,0x23FF), (0x2460,0x24FF), (0x2500,0x257F), (0x2580,0x259F),
            (0x25A0,0x25FF), (0x2600,0x26FF), (0x2700,0x27BF), (0x2B00,0x2BFF),
            (0x3000,0x303F), (0x3040,0x30FF), (0x4E00,0x9FFF), (0xFE00,0xFE0F),
            (0xFF00,0xFFEF)]
  cps = {c for lo,hi in ranges for c in range(lo,hi+1)}
  for weight, dst in ((400,'NotoSansSC-Regular.otf'),(700,'NotoSansSC-Bold.otf')):
      font = TTFont('NotoSansSC-VF.ttf')
      instantiateVariableFont(font, {'wght': weight}, inplace=True, updateFontNames=False)
      o = subset.Options(); o.layout_features=['*']; o.notdef_outline=True
      o.recalc_bounds=True; o.drop_tables += ['BASE']
      s = subset.Subsetter(options=o); s.populate(unicodes=cps); s.subset(font)
      font.save(dst)
  PY
